# xgc2-h1-description

XGC2 leaf repository for **Unitree H1** description assets (URDF / MJCF / meshes).

This tree is a vendor-original snapshot. It is not yet the XGC visual-contract
default, and it is not pinned in
[xgc2-robot-description](https://github.com/XGC-Team/xgc2-robot-description).

Meshes and kinematics remain Unitree's. License is BSD-3-Clause, see `LICENSE`.
